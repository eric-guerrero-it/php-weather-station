# php-weather-station
Collaborative PHP/MySQL web application for displaying Arduino weather station data and daily/monthly statistics.

# PHP Weather Station

Collaborative web application developed with **PHP and MySQL** to display data collected by an Arduino-based weather station.

Developed together with **Ievgen Soloviov** as an academic project.

---

## 🌦️ Project Overview

The application displays weather data stored in a MySQL database, including:

- Temperature
- Humidity
- Atmospheric pressure
- Wind speed
- Weather station UTM position
- Daily statistics
- Monthly statistics

---

## 🛠️ Technologies

`PHP` · `MySQL` · `PDO` · `HTML5` · `CSS` · `XAMPP` · `Arduino`

The application was developed using native PHP without frameworks or JavaScript.

---

## 🗄️ Database

The `meteo` database stores:

- Weather station position
- Temperature
- Humidity
- Atmospheric pressure
- Wind speed
- Date and time of each measurement

The database can be created using:

`sql/meteo.sql`

---

## ▶️ Running the Project

1. Install and start **Apache** and **MySQL** using XAMPP.
2. Place the project inside the `htdocs` directory.
3. Import `sql/meteo.sql` into MySQL/phpMyAdmin.
4. Open the application in your browser.

Example:

`http://localhost/ServidorWeb2/index.php`
